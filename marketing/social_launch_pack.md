## 💼 1. LinkedIn Post (Professional / Founder / Open Source Story)

**Recommended Media:** Attach `assets/dashboard.png` or carousel with `assets/erlik_logo.jpg` & `assets/dashboard.png`.

```text
🚀 Excited to announce that ERLÍK is officially open-sourced on GitHub, Homebrew, and npm! 🐺

As engineers and AI practitioners, we’ve all used activity and focus tracking tools. But running heavy Python/Qt or Electron background daemons that consume 300MB+ RAM and constantly spin up CPU cycles felt counterintuitive.

So I built ERLÍK — a native, zero-memory Activity & Focus Intelligence suite built purely in Swift for Apple Silicon (ARM64).

⚡ Key Highlights:
• 🧠 Pure Apple Silicon Native (ARM64 Swift): ~8 MB RAM footprint, zero Rosetta dependency, and near-zero battery drain.
• 🤖 Next-Gen AGI & AI Agent Tracking: Automatically detects and segments active coding time across Antigravity, Claude Code, Cursor, Windsurf, Hermes, Devin, and LLMs.
• 🍎 Native macOS Status Bar Companion: Live focus time, RAM usage, and instant cache cleaning (flushes inactive memory and deep system caches).
• 🔒 100% Local-First & Privacy Guaranteed: All telemetry stays strictly in your local SQLite database (`erlik.db`). Zero cloud leaks.
• 🌍 Multi-language UI: Seamless English, Turkish, and Dutch toggle.
• 📦 ActivityWatch Standard Export: Direct JSON compatibility for your own data workflows.

📦 Installation:
Via Homebrew:
$ brew install halilertekin/erlik/erlik

Via npm:
$ npm install -g erlik
$ npx erlik start

Or clone from GitHub:
🔗 https://github.com/halilertekin/erlik

Proudly built for builders. Feedback and PRs are very welcome! 🚀

#OpenSource #Swift #AppleSilicon #MacOS #DeveloperTools #Productivity #AI #AGI #Engineering
```
